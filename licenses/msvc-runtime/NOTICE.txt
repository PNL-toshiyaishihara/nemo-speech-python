Microsoft Visual C++ runtime
============================

Windows wheels of nemo-speech bundle the Microsoft Visual C++ runtime DLLs
that the native libraries use, such as msvcp140.dll, vcruntime140.dll,
vcruntime140_1.dll and the OpenMP runtime vcomp140.dll. delvewheel copies
them, unmodified, into the nemo_speech.libs directory of the wheel when the
wheel is repaired.
